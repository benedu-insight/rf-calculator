# Benedu Insight · RF Calculator

강의용 모바일 RF 계산기 (단일 HTML).

**사용하기:** https://benedu-insight.github.io/rf-calculator/

| 메뉴 | 입력 | 결과 |
|---|---|---|
| Z 임피던스 | V, I (rms), 위상 θ, f | Z = R + jX, 전압·전류 파형, 오일러 공식 풀이 |
| V·I·θ | Z = R + jX, 기준값(P, V 또는 I) | V, I (rms), θ, P·Q·S·PF와 산출식 |
| Γ 반사계수 | Z, Z0 (기본 50 Ω) | Γ, \|Γ\|∠φ, Return Loss, Smith chart |
| VSWR | Z, Z0, f, 케이블 VF | VSWR·ISWR, 정재파 그래프, Vmax·Vmin 위치 |

기본 주파수는 13.56 MHz이며, 전압·전류는 rms 기준입니다.
